# pr-assets

This branch holds screenshots for pull request descriptions. It has no shared history with `main`.

- Put each PR's images in a new folder, for example `pr-12-short-name/`.
- Link to images by commit, not by branch:
  `https://raw.githubusercontent.com/famesjranko/minesweeper-flags/<commit>/<folder>/<file>.png`
- Do not delete, rewrite, or force-push this branch. Do not overwrite files that a PR already uses. Merged PRs load their images from here.
- Keep files small. Do not add videos or large GIFs.
